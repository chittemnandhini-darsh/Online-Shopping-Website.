# Online-Shopping-Website.
Online Shopping Website is a responsive web project developed using HTML, CSS, and JavaScript. It allows users to browse products, add items to a shopping cart, remove products, view the total price, and submit a contact form. The website is designed with a simple and user-friendly interface.

## ✨ Features

- 🏠 Home page
- 🛍️ Product listing
- 🛒 Add to Cart
- ❌ Remove from Cart
- 💰 Automatic total price calculation
- 📱 Responsive design
- 📩 Contact form
- 💳 Checkout button
- 🧭 Navigation menu

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
